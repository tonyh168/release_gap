# 失败原因

流程在步骤 03（服务启动）之前中断，推理服务始终未成功拉起。根据 failure_diagnosis.json：completed_steps 仅含 01（容器准备）、02（环境检测）、08（发布），pending_steps 包含 03（服务启动）及后续全部步骤，root_cause 记为「推理服务未运行」。中断原因为 Claude API 流式响应长时间卡顿（stream_idle_partial，首字节延迟达约 497 秒），会话在服务拉起前被判定无进展退出。这是自动化编排层的流程缺陷：分段执行时 seg3 在未校验 service_ok 的前提下执行了 08_release，而 V1/V2/V3 从未真正跑起来。

无任何版本的精度/性能数据产出。该失败为流程编排/会话稳定性问题，**不能证明 V2/V3 本身存在适配缺陷**——V2/V3 从未获得执行机会。
